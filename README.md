# MIE424-group13-project-shortcut-learning
In this project, we explore shortcut learning in an image-classification context with controlled conditions, investigating whether a robustness-oriented optimization objective reduces shortcut reliance. We do this by training on the CIFAR-10 dataset and augmenting a variable proportion of the training images of each class with a monochrome patch corresponding to that class, applied to the upper-left hand corner of the image. This creates a biased training dataset such that the shortcut is highly predictive of the ground-truth label. The two optimization tasks we compare are (1) Empirical Risk Minimization (ERM), which minimizes expected training loss, and (2) Group Distributionally Robust Optimization (GroupDRO), which seeks to minimize the worst-case performance for all groups. This implementation also includes the data processing pipeline and interpretabilty metrics via saliency maps.
